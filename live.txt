PROJECT FOLDER HELP
===================

featured/
---------
Admin: Hero section
Front end: Main hero background, gallery fallback, key features card background
Files: 1 image only (e.g. hero.jpg)
Format: JPG, PNG, or WebP
Tip: Wide image (~1920px). Keep under 5 MB if possible.

homepage/
---------
Admin: Hero section
Front end: Portal / homepage project listing cards
Files: 1 image only (e.g. listing.jpg)
Format: JPG, PNG, or WebP
Tip: Card crop (~800–1200px). Not the main hero.

pdf/
----
Admin: Hero section
Front end: "Download Brochure" button
Files: 1 PDF only (e.g. brochure.pdf)
Format: PDF only

gallery/
--------
Admin: Gallery
Front end: Project gallery grid and lightbox
Files: Many images
Naming: 01.jpg, 02.jpg, 03.jpg (order by filename)
Tip: ~1600px wide is enough.

price-slider/
-------------
Admin: Price Slider
Front end: Price slider section
Files: Many images
Naming: 01.jpg, 02.jpg, 03.jpg

pricing-place/
--------------
Admin: Pricing place
Front end: Pricing / plan cards
Files: One image per card by order
Naming: 01.jpg = 1st card, 02.jpg = 2nd card, …
Tip: Create pricing cards in admin first; ZIP only fills images by position.

detail-tabs/
------------
Admin: Detail tabs
Front end: Images inside each detail tab panel
Structure:
  detail-tabs/tab-1/  → 1st detail tab in admin
  detail-tabs/tab-2/  → 2nd detail tab
  detail-tabs/tab-3/  → 3rd detail tab
Naming inside each tab: 01.jpg, 02.jpg, 03.jpg
Important:
  - Do NOT name folders after tab titles — use tab-1, tab-2, tab-3 only.
  - Create tab content in admin first; ZIP only adds images.
  - Extra tab folders with no matching admin tab are skipped (warning).

vr-tour/
--------
Admin: VR Tour
Front end: Virtual tour promo block
Files: 1 image only
Tip: VR URL is set separately in admin.

invest/
-------
Admin: Testimonials + Invest
Front end: "Why invest" section image
Files: 1 image only

PROJECT — NOT IN ZIP
--------------------
- Interactive map overlay → Interactive map tab (PNG/SVG + position)
- Featured video / Videos → YouTube URLs in admin
- Amenities & location, Booking, SEO, Address → text/content only

DHA PHASE FOLDER HELP
=====================

featured/
---------
Admin: Featured / banner image
Front end: Phase hero / banner (also gallery fallback)
Files: 1 image only (e.g. banner.jpg)
Format: JPG, PNG, or WebP
Tip: Wide hero image (~1920px).

card/
-----
Admin: Card image
Front end: DHA listing cards / phase tiles (square preferred)
Files: 1 image only (e.g. card.jpg)
Format: JPG, PNG, or WebP
Tip: ~800×800px recommended.

pdf/
----
Admin: Phase brochure (PDF)
Front end: Brochure download on phase page
Files: 1 PDF only (e.g. brochure.pdf)
Format: PDF only

gallery/
--------
Admin: Image gallery
Front end: Phase image gallery grid
Files: Many images
Naming: 01.jpg, 02.jpg, 03.jpg (order by filename)
Tip: ~1200×800px (3:2) recommended.

plot-maps/
----------
Admin: Plot maps
Front end: Plot / layout map images on phase page
Files: Many images
Naming: 01-masterplan.jpg, 02-sector-a.jpg (order by filename)
Tip: Filename (without extension) is used as the map title in admin.
     You can edit titles later in the DHA phase edit form.


DHA PHASE — NOT IN ZIP
----------------------
- Interactive map overlay → Interactive map section on phase edit (PNG/SVG)
- Video gallery → YouTube embed codes in admin (not image files)
- Attractions images → text/content fields in admin (optional future)
- Map coordinates / Google embed → Map section text fields

--------------------------------------------------------------------------------
GENERAL RULES (both Projects & DHA Phases)
--------------------------------------------------------------------------------
- Single-file folders → only 1 file allowed (extra files: first used + warning)
- Multi-file folders → use 01-, 02-, 03- prefixes for display order
- Allowed images: JPG, PNG, WebP (GIF accepted)
- Avoid spaces in filenames; use hyphens
- Unknown folders are ignored (warning) — never guessed
- Always preview before Confirm import
- Max ZIP size default: 200 MB (env: PROJECT_BULK_MEDIA_MAX_ZIP_KB /
  DHA_PHASE_BULK_MEDIA_MAX_ZIP_KB). Raise PHP upload_max_filesize /
  post_max_size on the live server to match.
