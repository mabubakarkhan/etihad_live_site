C. SITE-WIDE FIRST-TIME VISITOR POPUP
--------------------------------------------------------------------------------

A new first-time visitor popup was added across the website (homepage and
inner pages).

What the visitor sees:
- Light, attractive branded popup (cream/white with gold accents)
- Etihad logo
- Promotional message (Phase-X / Future of Lahore dummy content included)
- Optional custom background image (upload from admin)
- If no background image is uploaded, a clean branded panel is used instead
- Soft background blur (page still visible behind the popup – not too heavy)
- Comfortable spacing and padding

How it works:
1. Front side shows the promotional message and a “Contact Us” button
2. Clicking Contact Us flips the card smoothly to a short form
3. Form fields: Name, Phone, City
4. After successful submit, the popup does not show again for that visitor
5. Closing without submit also respects first-visit rules (shown once per visitor)

Admin control:
- New menu: Admin → First visit popup
- Enable / disable popup
- Edit eyebrow, heading, subheading, body text
- Edit button labels
- Show / hide logo
- Upload or remove background image
- Optional delay before showing
- Temporary “show every time” testing option (can be turned off for live use)

Leads from popup:
- Saved into Contact Messages
- Clearly labelled as “Popup first-time visitor”
- City is captured and visible in the message detail
- Admin can filter contact messages by source
